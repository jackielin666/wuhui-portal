# 五惠系統入口網站（wuhui-portal）

集中連結五惠食品各應用系統的入口網頁。

- 系統清單都放在 **`systems.json`**，**以後只改這個檔案**就好。
- 清單正本在 Google Sheet「五惠系統清單」。改網站之前，先確認 Sheet 已經更新。

---

## 檔案說明

| 檔案 | 用途 | 需要改嗎？ |
|---|---|---|
| `systems.json` | 系統清單 | ✅ 新增／修改系統時改這個 |
| `index.html` | 網頁畫面與功能 | ❌ 不用動 |
| `logo.png` | 五惠 Logo | ❌ 不用動 |
| `CLAUDE.md` | 給 AI 看的開發規範（配色等） | ❌ 不用動 |
| `.github/workflows/check-links.yml` | 自動檢查連結 | ❌ 不用動 |

## 一、如何新增一個系統

### 步驟 1：打開 systems.json 的編輯畫面
1. 打開瀏覽器，進入 GitHub 的 `wuhui-portal` Repo。
2. 點檔案清單中的 **`systems.json`**。
3. 點右上角的 **鉛筆圖示 ✏️**（Edit this file）。

### 步驟 2：複製一段現有的系統資料
每個系統是一段用 `{ }` 包起來的資料，例如：

```json
    {
      "name": "包裝產能儀表板",
      "category": "製造",
      "users": "管理部/製造課",
      "status": "開發/測試中",
      "description": "提供成品包裝每日人力及工時紀錄資料輸入頁面。",
      "note": "",
      "url": "https://jackielin666.github.io/packaging-capacity-dashboard/",
      "color": "",
      "icon": "package",
      "visible": true
    },
```

1. 依 Google Sheet 的排列順序，找到新系統**前一個**系統的那一段。
2. 從 `{` 複製到 `},`（包含逗號）。
3. 貼在它的下一行。

> 網頁上卡片的先後順序，就是 systems.json 裡的排列順序，所以請和 Google Sheet 保持一致。
> 類別的順序（品保 → 製造 → 工務 → 資材）由檔案最上方的 `categories` 決定。

### 步驟 3：修改內容

| 欄位 | 要填什麼 | 範例 |
|---|---|---|
| `name` | 系統名稱 | `"進料檢驗"` |
| `category` | 類別，只能填：`製造`、`品保`、`工務`、`資材` | `"品保"` |
| `users` | 主要使用者（畫面上不顯示，與 Google Sheet 同步用） | `"品保課"` |
| `status` | 只能填：`上線`、`開發/測試中`、`計劃中` | `"上線"` |
| `description` | 簡短說明（建議 40 字內） | `"提供品保進料檢驗即時記錄"` |
| `note` | 內部備註，畫面上不會顯示，沒有就留 `""` | `""` |
| `url` | 完整網址，要有 `https://` | `"https://xxx.vercel.app"` |
| `color` | 系統代表色，**沒有就留 `""`**（會用預設淺灰） | `""` |
| `icon` | 圖示名稱，從下方「圖示清單」挑一個 | `"search"` |
| `visible` | 要顯示填 `true`，不顯示填 `false`（不加引號） | `true` |

### 步驟 4：更新日期
把檔案最上方的 `"updated": "2026-09-23"` 改成今天的日期。

### 步驟 5：存檔
1. 點右上角綠色按鈕 **Commit changes...**。
2. 說明欄填寫例如「新增 進料檢驗 系統」。
3. 再按一次 **Commit changes**。

### 步驟 6：確認
1. 點 Repo 上方的 **Actions** 分頁。
2. 看最新一筆「檢查系統連結」：
   - ✅ 綠色勾勾：網址都正常。
   - ❌ 紅色叉叉：點進去看哪個網址打不開，回去修正。
3. 打開入口網站並重新整理，確認新卡片出現在正確的類別。

## 二、如何修改說明或網址

1. 按照「一、步驟 1」打開 `systems.json` 的編輯畫面。
2. 按 `Ctrl + F`（Mac 按 `Cmd + F`）搜尋系統名稱，找到那一段。
3. **只改 `" "` 雙引號裡面的文字**，不要刪到引號、冒號、逗號。
   - 改說明 → 改 `description`
   - 改網址 → 改 `url`
   - 系統正式上線 → 把 `status` 從 `"開發/測試中"` 改成 `"上線"`（「測試中」標籤會自動消失）
   - 暫時不顯示 → 把 `visible` 改成 `false`
4. 更新最上方的 `updated` 日期。
5. 按 **Commit changes** 存檔，再到 **Actions** 確認是綠色勾勾。

## 三、常見錯誤（改完網頁變空白時先看這裡）

網頁出現「無法讀取系統清單」，幾乎都是 `systems.json` 的格式錯了：

| 錯誤 | 錯誤寫法 | 正確寫法 |
|---|---|---|
| 少了逗號 | `"users": "品保課"` ⏎ `"status": ...` | `"users": "品保課",` |
| 最後一個系統後面多了逗號 | `... }, ]` | `... } ]` |
| 用了全形引號 | `“上線”` | `"上線"` |
| true/false 加了引號 | `"visible": "true"` | `"visible": true` |

**檢查方法**：把 systems.json 的全部內容貼到 <https://jsonlint.com>，按 Validate JSON，它會告訴您第幾行有錯。

> 萬一救不回來：在 GitHub 點 systems.json → **History** → 找到上一個正常的版本，把內容複製回來。

## 五、在自己電腦預覽（進階，可選）

直接雙擊 `index.html` 會顯示「無法讀取系統清單」，這是瀏覽器的安全限制，不是壞掉了。請用下列方式預覽：

1. 在 GitHub Repo 頁面點綠色 **Code** 按鈕 → **Download ZIP**，然後解壓縮。
2. 打開解壓縮後的資料夾，在資料夾空白處按 `Shift + 右鍵` → **在終端機中開啟**（Mac：在「終端機」輸入 `cd ` 後，把資料夾拖進去，再按 Enter）。
3. 輸入下面這行後按 Enter：
   ```
   python -m http.server 8000
   ```
   （如果顯示找不到 python，Mac 請改用 `python3`；Windows 可以到 Microsoft Store 安裝「Python 3」。）
4. 打開瀏覽器，進入 <http://localhost:8000>。
5. 看完後回到終端機按 `Ctrl + C` 關閉。

## 規範摘要
- 不設登入，不在任何檔案放帳號、密碼。
- 網頁有 `noindex, nofollow`，搜尋引擎不會收錄（但**知道網址的人仍然可以打開**）。
- 配色規範詳見 `CLAUDE.md`。五惠紅只用在 Logo。
